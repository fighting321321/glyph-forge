# 参考资料

本文件用于持续记录 GlyphForge 开发过程中值得研究的资料。

当前处于 Phase 0，因此先建立分类，后续每条参考应补充“为什么有用”，而不是只堆链接。

## 设计参考

后续若某套字体或视觉作品成为 GlyphForge 的风格研究对象，应记录：

1. 名称；
2. 来源；
3. 关注的设计特征；
4. 可以学习的原则；
5. 不应该直接复制的部分。

## AI / ML

当前不作为优先技术路线。

只有在出现明确问题后，再调研对应方向，例如：

- 字形相似性分析；
- 光学校正辅助；
- 缺失字形建议；
- 风格一致性检测。

任何 AI 方案都应先说明它具体替代或辅助哪一步，而不是因为“生成字体”就默认采用生成模型。
